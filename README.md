# Raymond Jefa Duma — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — main portfolio page
- `styles.css` — responsive design and theme
- `script.js` — mobile navigation, dark/light mode and scroll animations
- `Raymond_Duma_CV.pdf` — CV linked from the portfolio

## Publish with GitHub Pages

1. Create a GitHub repository named exactly:
   `YOUR-GITHUB-USERNAME.github.io`
2. Upload all files from this folder to the repository.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Your site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io`

GitHub Pages supports user sites using the `<username>.github.io` repository format.

## Before publishing

Replace/add:
- GitHub profile URL
- LinkedIn URL, if desired
- Project screenshots
- Public GitHub repository links for projects that can be shared
- A professional profile photo, if desired

Do not publish confidential client source code, credentials, API keys or private company information.
